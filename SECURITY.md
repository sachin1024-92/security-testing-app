# Security Policy

## Supported Versions
Only the latest main branch is supported for security updates.

## Reporting a Vulnerability
Please open a private security advisory or contact the Security Maintainer:
**Sachin Majhee** (@sachin1024-92)

This project supports defensive research on hardware security and AI-accelerator architectures, including vulnerability analysis and secure design validation.

## Security Maintainer Role
The Security Maintainer is responsible for:
- Reviewing security-related pull requests
- Updating threat models related to AI accelerator hardware security
- Ensuring the toolkit remains aligned with ethical defensive research practices
- Supporting vulnerability analysis and secure design validation workflows
